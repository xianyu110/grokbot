## 先看结论

- **Grok Bot ≠ grok.com 聊天**：它是跑在云端电脑上的 AI 同事（登录、点界面、定时、协作）。
- 多 Bot **共用一台云电脑**，不是安全隔离。
- 外发、付款、删数据、改生产：**永远放在审批后面**。
- 稳用法：`窄职责 Bot → 手动跑通 → Skill → 例程`。
