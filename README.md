## 开启 Pages（约 30 秒）

1. 打开仓库 **Settings → Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 `main`，文件夹选 **`/docs`**
4. Save，等 1–2 分钟打开上面的链接

也可把 Pages Source 设为 **GitHub Actions**，使用仓库内 `.github/workflows/pages.yml`。

## 本地预览

```bash
cd docs
python3 -m http.server 8080
```
