## 正文

今天把 Railway 上跑的 Hermes Agent 直接删了。花了一下午，全部工作流和项目都切到了 Grok Bot，也重新给这些 Bot 理了一下岗位和汇报协作关系。bot 不是越多越好、非必要也不要拉群，要平衡 好 Token 效率。

顺手给当前的 9 个 Personal Agent 排了个「从夯到拉」，纯属个人看法:

🔴 夯：
Grok Bot @bot ，对 X 的用户非常友好，每天有1000次免费 X search 额度-根本用不完，这意味着基本是拥有实时 X 数据，而 X 上英文区有非常多优质信息源，30刀/月的 Premium 订阅才能用上

🟠 顶级：
Muse @Muse ，Meta 是少有的擅长ToC 的美国公司，上手门槛非常低，免费额度很多
Duet @claudeai ，Opus 5.5 驱动，不 NB 也不行，20刀/月的订阅就能上手

🟡 人上人：
Dot @OpenAI ，藏在 ChatGPT 里，容易忘事定时任务也不按时跑，100刀/月的订阅才能用上，开放爱感觉是有点嗨了
Instinct @instinct ，不收费随便蹬，就是有点慢，适合砍账单和买东西
Cue @CueAgents ，我最喜欢的是能打电话收发短信

⚪ NPC：
Hermes Agent @NousResearch ，开源适合开发者折腾，需要自己部署和配置各种 Key，上手有点难度
Gemini Spark @GeminiApp ，被 Gemini 并进了 Task，但其实是一个 类 Personal Agent 的产品，普通用户绝对够用。

⚫ 拉完了：
OpenClaw @openclaw ，一言难尽，我已经退坑很久了。

这个排名，估计会有很多人不同意。

为了跑 Hermes 才订阅的 Railway，现在上面还剩 8 GB 内存、8 vCPU、100 GB 硬盘的额度，得想想怎么利用一下。
